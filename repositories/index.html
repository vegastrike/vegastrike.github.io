Vega Strike Linux Repositories

Official static repositories for Fedora, openSUSE, Rocky Linux / RHEL, Debian, and Ubuntu.

Updated: November 22, 2026 • Packages served directly from GitHub Releases CDN
Note: Vega Strike provides two release channels:
  • Stable Channel (Default): Official releases (e.g. 0.9.1, 0.9.0, 0.8.0). Enabled by default.
  • Testing Channel (Opt-in): Latest preview alphas and betas (e.g. 0.10.x, 0.11.x). Disabled by default.
Available Packages:
  • vegastrike — Core Game Engine
  • vegastrike-upon-the-coldest-sea — Vega Strike: Upon the Coldest Sea Assets (also installable as vsutcs)
  • Fedora / RPM
  • openSUSE / Zypper
  • Rocky Linux / EL
  • Debian
  • Ubuntu / Mint

Fedora (DNF / RPM)

1. Add the Repository File

sudo dnf config-manager --add-repo https://www.vega-strike.org/repositories/fedora/vegastrike-fedora.repo

Or download: Download vegastrike-fedora.repo

Stable Channel (Default)

Installs the latest official stable release (e.g. 0.9.1):

sudo dnf install vegastrike vegastrike-upon-the-coldest-sea

Also installable using the alias: sudo dnf install vegastrike vsutcs

Testing Channel (Alphas & Betas: 0.10.x, 0.11.x)

To install preview builds or alphas:

sudo dnf install --enablerepo=vegastrike-testing vegastrike vegastrike-upon-the-coldest-sea

To permanently enable testing: sudo dnf config-manager --set-enabled vegastrike-testing

openSUSE Leap (Zypper / YaST)

1. Add the Repository

sudo zypper addrepo https://www.vega-strike.org/repositories/opensuse/vegastrike-opensuse.repo
sudo zypper refresh

Stable Channel (Default)

sudo zypper install vegastrike vegastrike-upon-the-coldest-sea

Testing Channel (Alphas & Betas: 0.10.x, 0.11.x)

sudo zypper install --from vegastrike-testing vegastrike vegastrike-upon-the-coldest-sea

Rocky Linux / RHEL / CentOS Stream (DNF)

1. Add the Repository

sudo dnf config-manager --add-repo https://www.vega-strike.org/repositories/rocky/vegastrike-rocky.repo

Stable Channel (Default)

sudo dnf install vegastrike vegastrike-upon-the-coldest-sea

Testing Channel (Alphas & Betas: 0.10.x, 0.11.x)

sudo dnf install --enablerepo=vegastrike-testing vegastrike vegastrike-upon-the-coldest-sea

Debian (APT)

Stable Channel (Default)

Configures the repository for stable releases (component main):

sudo curl -sSL https://www.vega-strike.org/repositories/debian/vegastrike.sources -o /etc/apt/sources.list.d/vegastrike.sources
sudo apt update
sudo apt install vegastrike vegastrike-upon-the-coldest-sea

Testing Channel (Alphas & Betas: 0.10.x, 0.11.x)

To enable preview testing builds (component testing):

echo "deb [trusted=yes] https://www.vega-strike.org/repositories/debian $(lsb_release -cs) testing" | sudo tee /etc/apt/sources.list.d/vegastrike-testing.list
sudo apt update
sudo apt install vegastrike vegastrike-upon-the-coldest-sea

Channel & Repository Layout

Each distribution provides separate Stable and Testing repodata:

  • Fedora Stable: /repositories/fedora/$releasever/$basearch/repodata/repomd.xml
  • Fedora Testing: /repositories/fedora-testing/$releasever/$basearch/repodata/repomd.xml
  • openSUSE Stable: /repositories/opensuse/leap/$releasever/$basearch/repodata/repomd.xml
  • openSUSE Testing: /repositories/opensuse-testing/leap/$releasever/$basearch/repodata/repomd.xml
  • Rocky Linux Stable: /repositories/rocky/$releasever/$basearch/repodata/repomd.xml
  • Rocky Linux Testing: /repositories/rocky-testing/$releasever/$basearch/repodata/repomd.xml
  • Debian & Ubuntu: Component main (Stable) and Component testing (Alphas/Betas)

All package files stream on demand from official GitHub Release binaries.
