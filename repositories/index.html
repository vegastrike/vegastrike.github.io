Vega Strike Linux Repositories

Official static repositories for Fedora, openSUSE, Rocky Linux / RHEL, Debian, and Ubuntu.

Updated: November 22, 2026 • Packages served directly from GitHub Releases CDN
Note: Vega Strike is packaged into two components: the Engine (vegastrike) and the Game Assets (vsutcs). Both are available through these repositories.
  • Fedora / RPM
  • openSUSE / Zypper
  • Rocky Linux / EL
  • Debian
  • Ubuntu / Mint

Fedora (DNF / RPM)

Supports Fedora 40, 41, 42, 43, and 44 (x86_64).

1. Add the Repository

sudo dnf config-manager --add-repo https://www.vega-strike.org/repositories/fedora/vegastrike-fedora.repo

Or download the repo file manually to /etc/yum.repos.d/vegastrike-fedora.repo: Download vegastrike-fedora.repo

2. Install Vega Strike

sudo dnf install vegastrike vsutcs

openSUSE Leap (Zypper / YaST)

Supports openSUSE Leap 15.6 and Leap 16.0 (x86_64).

1. Add the Repository

sudo zypper addrepo https://www.vega-strike.org/repositories/opensuse/vegastrike-opensuse.repo
sudo zypper refresh

Or download the repo file manually to /etc/zypp/repos.d/vegastrike-opensuse.repo: Download vegastrike-opensuse.repo

2. Install Vega Strike

sudo zypper install vegastrike vsutcs

Rocky Linux / RHEL / CentOS Stream (DNF)

Supports Rocky Linux 8, 9, and 10 (x86_64).

1. Add the Repository

sudo dnf config-manager --add-repo https://www.vega-strike.org/repositories/rocky/vegastrike-rocky.repo

Or download: Download vegastrike-rocky.repo

2. Install Vega Strike

sudo dnf install vegastrike vsutcs

Debian (APT)

Supports Debian Bookworm (12) and Trixie (13) (amd64).

1. Configure the Repository

Using the modern deb822 sources format (recommended):

sudo curl -sSL https://www.vega-strike.org/repositories/debian/vegastrike.sources -o /etc/apt/sources.list.d/vegastrike.sources
sudo apt update

Or traditional sources.list.d entry:

echo "deb [trusted=yes] https://www.vega-strike.org/repositories/debian $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/vegastrike.list
sudo apt update

2. Install Vega Strike

sudo apt install vegastrike vsutcs

Direct release downloads are also accessible at Vega Strike Engine Releases.

Repository Structure Overview

Each repository conforms to the native package manager specifications:

  • /repositories/fedora/$releasever/$basearch/repodata/repomd.xml
  • /repositories/opensuse/leap/$releasever/$basearch/repodata/repomd.xml
  • /repositories/rocky/$releasever/$basearch/repodata/repomd.xml
  • /repositories/debian/dists/$suite/main/binary-amd64/Packages.gz
  • /repositories/ubuntu/dists/$suite/main/binary-amd64/Packages.gz

Packages are streamed on demand directly from official GitHub Release binaries.
